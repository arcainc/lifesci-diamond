# 3.2.P.1 Description and Composition of the Drug Product

**Product:** Calvorastat for injection, 100 mg/vial
**Applicant:** Brookline Therapeutics, Inc. | **NDA:** 229604
**Document number:** BRK-CLV-P1 | **Version:** 2.0 | **Date:** 30 June 2026

## 1. Description

Calvorastat for injection is a sterile, preservative-free, lyophilized powder for intravenous infusion after reconstitution and dilution. Each single-dose vial is reconstituted with 5.0 mL Sterile Water for Injection to give a solution containing 20 mg/mL calvorastat, pH 5.5 to 7.0 (typical 6.3).

## 2. Composition

Table 3.2.P.1-1 Composition per vial

| Component                              | Quality standard     | Function                                | Quantity per vial    |
| -------------------------------------- | -------------------- | --------------------------------------- | -------------------- |
| Calvorastat                            | In-house (3.2.S.4.1) | Active                                  | 105 mg (a)           |
| Mannitol                               | USP/Ph. Eur.         | Bulking agent                           | 150 mg               |
| Sodium phosphate monobasic monohydrate | USP                  | Buffer                                  | 3.9 mg               |
| Sodium phosphate dibasic heptahydrate  | USP                  | Buffer                                  | 7.2 mg               |
| Water for injection                    | USP                  | Solvent (removed during lyophilization) | q.s. to 5.25 mL fill |

(a) Each vial contains an overfill of 5 mg (5%) so that 100 mg calvorastat (5.0 mL of reconstituted solution) can be withdrawn, as justified in 3.2.P.2.2.3. The labeled strength is 100 mg per vial.

## 3. Container closure system

10R Type I borosilicate glass vial (nominal capacity 10 mL), 20 mm bromobutyl rubber lyophilization stopper with fluoropolymer film coating, and 20 mm aluminum flip-off seal. See 3.2.P.7.

## 4. Diluent

Not co-packaged. Sterile Water for Injection, USP, is used for reconstitution and 0.9% Sodium Chloride Injection, USP, for dilution; both are commercially available.
