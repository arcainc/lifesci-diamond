# 3.2.P.5.1 Specification and Testing Sites (excerpt)

**Product:** PELLAVIG 10% (immune globulin intravenous, human), liquid, 10% protein
**Applicant:** Harrowgate Plasma Therapeutics, Inc., Clayton, NC | **BLA:** 197512
**Version:** 6.0 | **Date:** 4 April 2025

## 1. Release specification (excerpt)

| Test                              | Method                                       | Acceptance criterion                                                | Testing location                       |
| --------------------------------- | -------------------------------------------- | ------------------------------------------------------------------- | -------------------------------------- |
| Protein content                   | Kjeldahl nitrogen (HPT-QC-101)               | 95 to 105 mg/mL                                                     | Harrowgate QC, Building 4, Clayton, NC |
| Molecular size distribution       | HPSEC (HPT-QC-114)                           | Monomer + dimer ≥ 95%; polymers and aggregates ≤ 2%; fragments ≤ 3% | Harrowgate QC, Building 4, Clayton, NC |
| Anti-complementary activity (ACA) | Ph. Eur. 2.6.17-based procedure (HPT-QC-122) | ≤ 1 CH50 unit consumed per mg protein                               | Harrowgate QC, Building 4, Clayton, NC |
| Prekallikrein activator (PKA)     | Chromogenic assay (HPT-QC-125)               | ≤ 35 IU/mL                                                          | Harrowgate QC, Building 4, Clayton, NC |
| Anti-A and anti-B hemagglutinins  | Indirect method (HPT-QC-131)                 | ≤ 1:64                                                              | Harrowgate QC, Building 4, Clayton, NC |
| Anti-D                            | Flow cytometry (HPT-QC-133)                  | ≤ 12 mIU/mL                                                         | Harrowgate QC, Building 4, Clayton, NC |
| Measles antibody                  | Neutralization (HPT-QC-140)                  | Meets the minimum relative to the CBER reference preparation        | Harrowgate QC, Building 4, Clayton, NC |
| Sterility                         | 21 CFR 610.12                                | No growth                                                           | Harrowgate QC Microbiology, Building 4 |
| Pyrogen / endotoxin               | LAL (HPT-QC-150)                             | ≤ 0.5 EU/mL                                                         | Harrowgate QC Microbiology, Building 4 |

The same tests except sterility, measles antibody and anti-D are performed on stability at the Harrowgate QC laboratory.

## 2. In-process control (excerpt)

| Step                                  | Test                   | Limit           | Testing location                       |
| ------------------------------------- | ---------------------- | --------------- | -------------------------------------- |
| Final bulk, before sterile filtration | Bioburden (HPT-QC-155) | ≤ 10 CFU/100 mL | Harrowgate QC Microbiology, Building 4 |

Building 4 is within the licensed Clayton manufacturing location (fractionation, purification, formulation, aseptic filling and QC).
