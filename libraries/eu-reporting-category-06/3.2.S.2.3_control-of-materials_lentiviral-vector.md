# 3.2.S.2.3 Control of Materials: Lentiviral Vector LV-LUM-19

**Product:** Lumacel | **Document:** FCM-LUM-M3-S23-LVV | **Version:** 4.0 | **Status:** Approved

## 1. Role of the vector

LV-LUM-19 is a third-generation, self-inactivating, VSV-G pseudotyped lentiviral vector encoding the anti-CD19 chimeric antigen receptor. It is a starting material for the Lumacel active substance and is added at the transduction step (see 3.2.S.2.2).

## 3. Summary of vector manufacturing process

1. Expansion of PCB-293T-02 in suspension culture.
2. Transient transfection with the four plasmids in a single-use stirred-tank bioreactor, 200 L working volume.
3. Harvest at 48 hours, nuclease treatment and depth-filter clarification.
4. Anion exchange chromatography capture.
5. Tangential flow filtration (concentration and buffer exchange).
6. Sterile filtration, formulation and fill into 2 mL cryovials; storage at ≤ -65 °C.

## 4. Vector specification

| Test                             | Method                                       | Acceptance criterion |
| -------------------------------- | -------------------------------------------- | -------------------- |

| Physical titre                   | p24 ELISA                                    | Report result        |

| Replication-competent lentivirus | Cell-based amplification, qPCR endpoint      | Not detected         |
| Sterility                        | Ph. Eur. 2.6.1                               | Sterile              |
| Bacterial endotoxins             | Ph. Eur. 2.6.14                              | ≤ 5 EU/mL            |
| Mycoplasma                       | Ph. Eur. 2.6.7                               | Not detected         |
